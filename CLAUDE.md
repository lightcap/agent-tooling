# Claude Guidance

This repository is intended to be published publicly. Keep all changes generalized and safe for public release.

- Do not commit private machine paths, usernames, hostnames, organization names, credentials, tokens, API keys, or local MCP server details.
- Keep examples generic; use placeholders such as `example`, `mcp.example.com`, and fake environment variable names.
- Do not commit `mcp-sync/servers.json`, generated `*.state.json` files, backups, or copied client config files.
- Sanitize logs, test fixtures, docs, and review notes before adding them to the repo.
- Prefer reusable public documentation over personal workflow notes.
